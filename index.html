פתיחת הטבלה

הטבלה שמורה ב-repo פרטי ב-GitHub. כדי לפתוח אותה במכשיר הזה, מדביקים את המפתח (token) שיצרת. המפתח נשמר רק בדפדפן הזה, ובלעדיו אי אפשר לראות כאן כלום.

איך יוצרים מפתח
  1. נכנסים ל-github.com/settings/personal-access-tokens/new
  2. ב-Repository access בוחרים Only select repositories ואז sky-plan-data
  3. ב-Permissions מוסיפים Contents ובוחרים Read and write
  4. לוחצים Generate token, מעתיקים את המפתח ומדביקים אותו כאן
